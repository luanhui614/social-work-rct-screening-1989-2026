# Research materials

The [README](../README.md) links the frozen methods, seven-category codebook, verbatim v2 prompt, documented model setup, negative-sampling provenance, reference decisions, data dictionary, source database attribution and reproducible numerical analysis.

The [complete count chain](COUNT_FLOW.md) and [quality reconciliation](DATA_QUALITY_STATUS.md) describe raw source IDs, cleaning exclusions, final model groups, original verification workload, cleaned evaluation denominators, the additional author decision, and final RCT counts. Machine-readable records are indexed in [Data](../data/README.md).

Current result tables and figures reproduce the frozen analysis version. The source abstracts, full-text PDFs, unpublished manuscript and personal reviewer files are not redistributed. Original source-file fingerprints remain in [provenance](../materials/source_document_provenance.json). Execution and sampling settings not established by retained materials remain explicitly unknown.
