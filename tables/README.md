# Manuscript tables

The three tables follow the numbering and content of the final manuscript:

1. [Classification categories, definitions and source screening yield](Table_1.md).
2. [Screening performance against final reference classifications](Table_2.md).
3. [RCT reports and rates by period](Table_3.md).

`scripts/reproduce.py` generates these tables. Table 1 reports original model-A classifications before cleaning; Tables 2 and 3 use the final verification and analysis denominators. Full annual, journal and conference-format distributions are available in `results/`.
